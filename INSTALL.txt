TRADYSQUIDS TRADEBOT UPGRADE

Replace these repository files with the files in this package:

  ford_scan.py
  requirements.txt
  .github/workflows/ford-scan.yml
  state/ford-plays-log.csv
  docs/index.html

Required GitHub Actions repository secrets:

  TRADIER_TOKEN
  TRADIER_BASE_URL
  DISCORD_WEBHOOK_URL
  DISCORD_BOT_TOKEN
  DISCORD_GUILD_ID

Discord requirements:

  Forum channel: trade-journal
  Text channels: scanner-feed, qualified-trades, entry-alerts,
                 position-updates, exit-alerts, wins, losses,
                 scratches, scanner-status, api-errors

  Keep scanner-status, api-errors, workflow-log, and admin-notes inside a
  private SYSTEM category. TradeBot verifies that @everyone cannot view
  these channels and refuses to post technical details if privacy is lost.

  Forum tags must contain these words; emoji prefixes are supported:
  OPEN, HOLDING, TARGET HIT, STOP WARNING, WIN, LOSS, SCRATCH

TradeBot permissions needed in the server/forum:

  View Channels
  Send Messages
  Embed Links
  Read Message History
  Send Messages in Threads
  Manage Threads

Behavior:

  - No brokerage orders are placed.
  - New scans support long calls, long puts, bull put-credit spreads, and
    bear call-credit spreads. The current Ford trend determines which
    direction is eligible.
  - Entries require a controlled daily market regime, 21-45 DTE, open
    interest of at least 100, option volume of at least 10, and a bid/ask
    spread no wider than 20% of midpoint.
  - There is no arbitrary per-scan or simultaneous-trade count cap.
    Every qualifying trade must still have defined maximum loss of $150
    or less. Existing positions continue to be monitored until they close.
  - Existing OPEN CSV plays are imported into trade-journal once.
  - New scanner plays get one forum post and permanent trade ID.
  - Open plays are repriced every scheduled run.
  - Discord receives material updates, not repetitive quote spam.
  - The local information engine monitors Ford without GitHub Actions,
    suppresses unchanged alerts, and stores recent observations in SQLite.
  - Slash commands provide quotes, technicals, charts, option-chain rankings,
    contract inspection, risk calculations, filings, education, performance,
    schedules, and health information.
  - Closed plays are tagged and routed to wins/losses/scratches.
  - The CSV is migrated automatically without deleting old rows.
